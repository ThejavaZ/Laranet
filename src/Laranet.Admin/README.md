# Laranet.Admin

Experimental, provider-neutral contracts for an optional administrative surface.

This package does not depend on EF Core, ASP.NET Core, Razor, or an authentication
system. It defines resource metadata, permission hooks, query/page contracts, and a
data adapter boundary. The prototype currently targets Razor Pages, SQLite, and
ASP.NET Core Identity in a separate sample application.

The API is not frozen. Do not treat this package as a stable release contract yet.
