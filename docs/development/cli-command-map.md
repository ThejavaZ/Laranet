# CLI Command Map

This document maps every command exposed by `Laranet.Cli`, the files it generates, its
flags, and the overlaps that were resolved during the CLI audit.

## Commands

| Command | Generates | Main flags |
| --- | --- | --- |
| `new` | A project from a template. | `--template`, `--layout`, `--sln`, `--with-*`, `--output`, `--namespace` |
| `make:model` | `Models/<Name>.cs` | `-o`, `-n`, `-f`, `--dry-run`, `--flat`, `-i` |
| `make:service` | `Services/<Name>Service.cs` | `-o`, `-n`, `-f`, `--dry-run`, `--flat`, `-i` |
| `make:controller` | `Controllers/<Name>Controller.cs` | `-o`, `-n`, `-f`, `--dry-run`, `--flat`, `-i` |
| `make:middleware` | `Middleware/<Name>Middleware.cs` | `-o`, `-n`, `-f`, `--dry-run`, `--flat`, `-i` |
| `make:all` | `Models/`, `Services/`, `Controllers/` together. | `-o`, `-n`, `-f`, `--dry-run`, `--flat`, `-i` |
| `make:resource` | `Contracts/<Name>Resource.cs` (API view model). | `-o`, `-n`, `--fields`, `-f`, `--dry-run`, `--flat`, `-i` |
| `make:crud` | Entity, DTOs, controller, and optional service/repository. | `-p`, `-c`, `--fields`, `-o`, `-n`, `-f`, `--dry-run`, `--flat`, `-i`, `--from-model`, `--scaffold` |
| `make:repository` | `Repositories/<Name>Repository.cs` scaffold. | `-o`, `-n`, `-f`, `--dry-run`, `--flat`, `-i` |
| `make:command` | `Commands/<Name>Command.cs` and optional handler. | `--mediator`, `--profile`, `--with-handler`, `--with-tests`, `-o`, `-n`, `-f`, `--dry-run`, `--flat`, `-i` |
| `make:query` | `Queries/<Name>Query.cs` and optional handler. | `--mediator`, `--profile`, `--with-handler`, `--with-tests`, `-o`, `-n`, `-f`, `--dry-run`, `--flat`, `-i` |
| `make:handler` | `Handlers/<Name>Handler.cs`. | `--profile`, `-o`, `-n`, `-f`, `--dry-run`, `--flat`, `-i` |

| `admin:check` | No files. Validates admin installation. | `--path`, `--json` |
| `list` | No files. Command catalog. | none |

## Resolved overlaps

| Overlap | Resolution |
| --- | --- |
| `make:resource` (old) generated model, service, and controller, overlapping with `make:crud`. | Renamed to `make:all`. `make:resource` now generates only an API Resource view model. |
| `make:crud` and `make:all` both generate controllers. | `make:all` is the small scaffold; `make:crud` is the database-backed CRUD surface. |
| `--force` could be mistaken for selecting generation mode. | `--force` only overwrites files. Mode selection uses `--from-model` and `--scaffold`. |
| `--profile` has different accepted values for CRUD and CQRS. | Documented separately; CRUD uses `simple`, `standard`, `clean`, `modular`; CQRS uses `simple`, `standard`, `clean`. |
| `--fields` is only valid for `make:crud` and `make:resource`. | Other generators do not accept it. |
| `make:dbcontext` and `make:crud` both mention entities. | `make:dbcontext` creates the context; `make:crud` uses an existing context. |

## Security findings

| ID | Severity | Finding | Resolution |
| --- | --- | --- | --- |
| CLI-SEC-001 | High | `make:dbcontext` generated a design-time factory with hardcoded connection strings. | The factory now reads `ConnectionStrings__<ContextName>` from the environment and throws a clear error when it is missing. |
| CLI-SEC-002 | Medium | Unknown commands previously relied only on the framework suggestion. | Unknown commands now use a Levenshtein-based suggestion with a clear next step. |
| CLI-SEC-003 | Medium | Generated controllers always used `Remove()` for deletion. | Soft-deletable entities now generate `IsDeleted` and `DeletedAt` updates. |
| CLI-SEC-004 | Low | No tenant boundary is generated by default. | Tenant filtering remains an application responsibility; the generator does not emit shared tenant state. |
| CLI-SEC-005 | Low | No generated file manifest exists yet. | Conflict protection remains through `GenerationWriter`; a hash manifest is planned as hardening. |

## Notes

- `about`, `route:list`, and `env` are not implemented commands.
- The CLI remains non-interactive by default and does not read from standard input unless `--interactive` is supplied.
- No secrets or credentials are written to disk or printed by any command.
