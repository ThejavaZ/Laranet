# Version 2 — Deferred and future work

**Status: Planning**

Version 2 collects work that was intentionally excluded from Version 1 and new
initiatives driven by real usage and community feedback. This document will be
refined after the first public release.

## Deferred from Version 1

- **Additional generators based on actual usage.** Add generators only when real
  projects demonstrate a recurring need, and justify each one individually.
- **Extensible conventions.** Allow projects to customize generated folders and
  namespaces, building on the existing `.laranet/templates` mechanism.

## Feedback-driven work

- Collect feedback from Version 1 users.
- Prioritize additions that solve demonstrated problems.
- Update this roadmap before starting implementation.

Additions must be justified by concrete use cases, not speculation. Version 2 must
preserve the Version 1 principles: native .NET behavior, provider neutrality,
optional integrations, editable generated code, and no mandatory runtime metadata.
